# 운세 & 예언 스튜디오

사주, 타로, 꿈해몽, 로또 번호 추천을 제공하는 정적 웹사이트입니다.

## 프로젝트 개요
- 사주 계산기
- 3장 타로 뽑기
- 꿈해몽 해석 생성기
- 로또 번호 추천
- 개인정보 수집 없음
- 브라우저 로컬 계산 중심 구조
- Google AdSense 승인 후 광고 배치 가능

## 주요 원칙
- 사용자 입력값은 서버로 전송하지 않습니다.
- 데이터베이스에 저장하지 않습니다.
- 쿠키, 로그, 추적 코드, 분석 도구를 사용하지 않습니다.
- 로컬 브라우저에서 계산 후 결과만 화면에 표시합니다.
- 광고는 Google AdSense 승인 후에만 삽입합니다.

## 파일 구조
- `index.html` : 메인 웹페이지
- `style.css` : 전체 스타일 시트
- `script.js` : 사주, 타로, 꿈해몽, 로또 로직
- `privacy-policy.html` : 개인정보처리방침
- `terms.html` : 이용약관
- `adsense-guide.md` : 광고 운영 가이드
- `adsense-checklist.md` : AdSense 신청 전 체크리스트

## 실행 방법
1. 저장소를 로컬에 다운로드합니다.
2. `index.html` 파일을 브라우저에서 직접 엽니다.
3. 사주/타로/꿈해몽/로또 기능을 사용합니다.

## 개인정보 보호 원칙
- 브라우저에서만 계산합니다.
- 서버 저장을 하지 않습니다.
- 사용자 데이터는 메모리 상에서만 처리합니다.
- 페이지를 닫으면 데이터가 사라집니다.
- 외부 추적 도구를 사용하지 않습니다.

## 광고 관련 안내
- 본 사이트는 광고 수익화를 목표로 구성되었지만,
- Google AdSense는 별도 승인 절차가 필요합니다.
- 승인 전에 광고 코드를 삽입하지 않는 것이 안전합니다.
- 승인 후 광고 영역을 추가하되, 개인정보 수집을 유지하지 않도록 운영합니다.

## 참고사항
- 이 프로젝트는 참고용 콘텐츠입니다.
- 사주/타로/꿈해몽/로또는 일반적인 운세 및 재미 요소로 제공됩니다.
- 실제 결과를 보장하거나 법적, 재정적 판단 근거로 사용하지 않습니다.

## 라이선스
현재 프로젝트는 기본 정적 웹사이트 형태로 제공되며, 별도 라이선스 없이 자유롭게 수정/확장할 수 있습니다.
