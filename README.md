# 운세 & 예언 스튜디오

정적 웹사이트 프로젝트입니다.

## 개요
- 사주 계산기
- 타로 3장 스프레드
- 꿈해몽 해석기
- 로또 번호 추천
- 개인정보 수집 없음
- Google AdSense 배치 영역 준비

## 빠른 실행
1. 이 폴더를 웹 서버로 실행하거나, 브라우저에서 `index.html` 을 직접 열어 사용합니다.
2. 사용자 입력은 브라우저에서만 처리되며 서버로 전송되지 않습니다.

## 개인정보 보호 원칙
- 서버로 데이터 전송 없음
- DB 저장 없음
- 쿠키/로컬스토리지 사용 없음
- 로그 추적 없음
- 외부 분석 도구 사용 없음

## 광고 배치 안내
- AdSense 승인 후 `index.html`의 광고 영역을 실제 Google AdSense 코드로 교체하면 됩니다.
- 광고 코드는 사용자 입력과 무관하게 안전하게 삽입해야 하며, 수집 정책을 유지해야 합니다.

## 폴더 구조
- `index.html` : 메인 페이지
- `style.css` : 스타일시트
- `script.js` : 기능 로직

## 주의사항
- 이 프로젝트는 데모/기본 웹사이트 구조입니다.
- 실제 로또 당첨 보장이나 사주 해석 전문성을 의미하지 않습니다.
- Google AdSense는 별도로 승인 절차가 필요합니다.
